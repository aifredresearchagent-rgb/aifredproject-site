# Aifred Project

Minimalistische, moderne Webseite für Geschichten, lokale Sagen und Märchen.

## Features

- Reines HTML, CSS und JavaScript (kein Framework)
- GitHub Pages kompatibel
- Responsive und mobil optimiert (iPhone/iPad)
- Ruhiges Dark-Mode-Design mit Fokus auf Lesbarkeit
- Hero-Section, Navigation, Kartenansicht, Footer

## Struktur

- `index.html` – Seitenstruktur und Inhalte
- `style.css` – Design, Typografie, Layout und Responsiveness
- `script.js` – Menülogik und dynamisches Footer-Jahr

## Nutzung

Einfach die Dateien in ein GitHub-Repository legen und auf GitHub Pages veröffentlichen.
